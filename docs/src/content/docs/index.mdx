## Your first API call

The first request returns the next deadline and whether a usable
point-in-time snapshot exists.

<Tabs syncKey="lang">
<TabItem label="curl">

```bash
curl -H "X-API-Key: $PREMIERLYTICS_API_KEY" \
  "https://api.premierlytics.com/v1/gameweeks/next?season=2026-2027"
```

</TabItem>

<TabItem label="JavaScript">

```js
const res = await fetch(
  "https://api.premierlytics.com/v1/gameweeks/next?season=2026-2027",
  {
    headers: {
      "X-API-Key": process.env.PREMIERLYTICS_API_KEY,
    },
  }
);

const gameweek = await res.json();
```

</TabItem>

<TabItem label="Python">

```python
import os
import httpx

r = httpx.get(
    "https://api.premierlytics.com/v1/gameweeks/next",
    params={"season": "2026-2027"},
    headers={
        "X-API-Key": os.environ["PREMIERLYTICS_API_KEY"],
    },
)

gameweek = r.json()
```

</TabItem>

## Why this exists

<CardGrid stagger>

<Card title="No historical leakage" icon="seti:clock">

Every historical feature derives from a capture made **strictly before**
its deadline.

Most FPL datasets expose end-of-gameweek state, which contains information
that was unavailable when managers made their decisions. Models trained on
that data often look excellent offline and disappoint in production.

</Card>

<Card title="The joins are already done" icon="puzzle">

Not a wrapper around FPL's API.

Cross-season player identity is resolved. Data is stored at fixture grain so
per-match scoring rules can be evaluated correctly. Competition is attached,
so a pre-season friendly is never mistaken for league form.

</Card>

<Card title="Built with provenance" icon="warning">

Every field has a source and every limitation is published.

Capture data, upstream statistics and derived features are separated, so you
always know where a value came from and what assumptions it carries.

</Card>

<Card title="Every competition" icon="star">

Premier League, Champions League, Europa League, Conference League, EFL Cup,
Community Shield, UEFA Super Cup and friendlies.

A midweek European tie is real fatigue and real injury risk, and most FPL
datasets simply do not include it.

</Card>

</CardGrid>

## Why not just use the FPL API?

The official Fantasy Premier League API is excellent for live fantasy
football. It is not designed as a historical research dataset.

Premierlytics adds:

- immutable snapshots before every deadline
- stable identifiers across seasons
- match-level statistics
- competition context
- reproducible historical feature generation

## What's included

| | |
|---|---|
| **Seasons** | 2024/25 and 2025/26 complete, 2026/27 accumulating |
| **Competitions** | Premier League, Champions League, Europa League, Conference League, EFL Cup, Community Shield, UEFA Super Cup, friendlies |
| **Per match** | xG, xA, xGOT, shots, tackles, interceptions, blocks, clearances, recoveries, minutes on/off |
| **Per fixture** | ClubElo at kickoff, rest days, matches in the previous 14 days |
| **Capture cadence** | Every 3 hours, tightening to every 15 minutes during the 6 hours before each deadline |

## Acknowledgements

This API builds on several excellent open datasets and projects.

### FPL-Core-Insights

Nearly all match-level statistics—xG, xA, defensive actions, ClubElo ratings
and competition coverage—come from **FPL-Core-Insights** by **olbauday**,
which also powers **fplcore.com**.

It solves one of the hardest parts of football data engineering: matching
match statistics to FPL player identities.

If Premierlytics is useful to you, that project deserves much of the credit.

### ClubElo

Club ratings originate from **ClubElo**, via Core Insights.

Because they are calculated from results rather than assigned manually, they
provide useful pre-match strength estimates, including for newly promoted
clubs.

### FotMob

Underlying match statistics originate from **FotMob**.

### Fantasy Premier League

Player prices, ownership, availability and official scoring originate from
the Fantasy Premier League API.

Premierlytics is an independent project and is not affiliated with or
endorsed by the Premier League or Fantasy Premier League.
